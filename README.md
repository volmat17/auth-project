# 🔐 Auth Project

Учебный проект по изучению backend-разработки на Go.

Цель проекта — шаг за шагом разобраться, как строятся современные сервисы авторизации: от простого HTTP-сервера до полноценного REST API с JWT-аутентификацией и базой данных.

---

## 🚀 Что будет реализовано

- 🌐 HTTP-сервер
- 📡 REST API
- 👤 Регистрация пользователей
- 🔑 Авторизация
- 🔒 Хеширование паролей (bcrypt)
- 🗄️ Хранение пользователей в SQLite
- 🎫 JWT-аутентификация
- 🛡️ Middleware для защиты маршрутов
- ⚠️ Обработка ошибок
- 🧪 Тестирование API

---

## 🛠️ Технологии

- Go
- net/http
- SQLite
- bcrypt
- JWT

---

## ▶️ Запуск проекта

```bash
go mod tidy
go run .
```

После запуска сервер будет доступен по адресу:

```
http://localhost:8080
```

---

## 📚 Цель проекта

Проект создаётся исключительно в учебных целях.

Основной акцент сделан не на скорости написания кода, а на понимании того:

- как работает HTTP;
- как устроен backend на Go;
- как происходит регистрация и авторизация пользователей;
- как организуется структура реального проекта.
